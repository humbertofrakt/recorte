Animação 2D por ossos, de graça, no navegador.

O Recorte é um programa para animar personagens 2D: você põe ossos num desenho, mexe nos ossos e grava a animação. Ele roda no navegador, sem instalar nada. O arquivo que ele grava, o .bone, é aberto: qualquer jogo ou programa pode ler, sem pedir licença a ninguém.

Por que isto existe

Um formato fechado morre com a empresa que o inventou. Um formato aberto sobrevive a ela. Foi o que aconteceu duas vezes:

Formato O que ele resolveu Por que pegou
PDF Documento que fica igual em qualquer máquina. Especificação aberta, estável, com validador. Virou norma ISO.
glTF Modelo 3D que passa de um programa para outro. Especificação aberta, validador na web, suíte de conformidade.
.bone Personagem 2D animado por ossos. É o que este projeto está tentando fazer.

Hoje não existe equivalente para 2D. Spine, DragonBones, Live2D e Creature guardam cada um o seu formato próprio. Quem anima fica preso ao programa que escolheu, e o trabalho morre junto com ele. O DragonBones parou; os arquivos ficaram.

O padrão é o arquivo, não o programa.
O programa é só a melhor forma de fazer esse arquivo.

As três embalagens

Um modelo de dados só, gravado de três jeitos. Um leitor descobre qual é pelos primeiros bytes do arquivo, nunca pelo nome.

Extensão O que é Quando usar
.bone Texto JSON. Abre em qualquer editor de texto. Enquanto se trabalha. Dá para ler, comparar e versionar.
.boneb Binário compacto, com os mesmos dados. Dentro do jogo. Cerca de 38% menor e carrega mais rápido.
.bonez Pacote ZIP: o boneco, a folha de imagens e as imagens juntos. Para entregar tudo num arquivo só.
