    Como ler o resultado

    ErroO arquivo não segue a especificação. Um programa que leia esse arquivo pode recusar ou desenhar errado.
    AvisoO arquivo é válido, mas alguma coisa chama atenção. Vale conferir.
    LinhaA linha do arquivo de texto onde o problema está. Só existe para .bone, que é texto.
    OndeO endereço do trecho dentro do arquivo, no formato JSON Pointer. Exemplo: /bones/3/parent é a propriedade parent do quarto osso.
    RegraA seção da especificação que manda nisso.
