# documentos/pesquisa/

O que os outros programas fazem. Fonte do manual de requisitos e dos planos.

| Pasta | O que é | Quando |
|:---|:---|:---:|
| **`nova pesquisa/`** | Spine, Spriter e DragonBones lidos a fundo no manual oficial. Uma pasta cada, com todas as funções e **286 prints** dos menus | 08/09/2026 |
| `menu/` | Organização de tela e menus: inventário do Recorte (`00`), os programas (`01` a `04`), a proposta (`05`), os fluxos do Spriter (`06`), a lista mestra de 52 itens (`07`) e as especificações (`08`) | 08/09/2026 |
| `manuais/` | Leitura dos manuais para o projeto do menu: Spine, Spriter, Live2D, DragonBones, Moho, Aseprite | 08/09/2026 |
| `pesquisa antiga/` | Os cinco primeiros relatórios, sobre 12 programas. Base do manual de requisitos. **Guardados, não apagados** | 06/09/2026 |

`menu/` e `manuais/` ficam à vista porque **os planos apontam para eles**:
`PLANO rodada 1`, `PLANO rodada 2`, `PROJETO DO MENU` e `POSSIBILIDADES NOVAS`.

Regra dos relatórios: o que não está na fonte oficial está marcado como **não confirmado**.
