**Sobre o PDF.** A Esoteric Software **não publica** o manual em PDF — só na web.
Este arquivo foi feito aqui: as 48 páginas do manual oficial, baixadas, limpas do
menu do site e impressas em PDF, com sumário e uma página por capítulo.
O texto e as figuras são os oficiais. Serve para ler sem internet.
Não é publicação oficial e não deve ser distribuído.

**Fonte:** `esotericsoftware.com/spine-user-guide` — 48 páginas, lidas em 08/09/2026.
Manual vivo e completo. É a referência mais forte das três.

**Como o print é nomeado:** o caminho da seção no manual, com `_` no lugar da barra.
`settings_settings-graph.png` veio de `/img/spine-user-guide/settings/settings-graph.png`.
