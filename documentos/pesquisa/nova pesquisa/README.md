## Os três manuais em PDF

Os três estão na pasta, para ler sem internet.

| Programa | Arquivo | Páginas | De onde veio |
|:---|:---|:---:|:---|
| **Spriter Pro** | `Spriter Pro - manual oficial 1.4.pdf` | 38 | **PDF oficial**, publicado pela BrashMonkey |
| **Spine** | `Spine User Guide - manual completo 2026-09-08.pdf` | 311 | **feito aqui.** A Esoteric só publica na web. As 48 páginas foram baixadas, limpas do menu do site e impressas |
| **DragonBones** | `DragonBones Pro - manual completo 2026-09-08.pdf` | 46 | **feito aqui.** A Egret nunca publicou em PDF e o site caiu. Remontado pelo Internet Archive |

Só o Spriter tem PDF oficial. Os outros dois eu montei: o texto e as figuras são
os oficiais, mas o arquivo não é publicação da empresa. É cópia de leitura,
para uso dentro do projeto. Não distribuir.
