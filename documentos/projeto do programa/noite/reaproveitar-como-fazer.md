# Como fazer — muitos bonecos, as mesmas animações

Uma ação por linha.

## As 4 animações prontas num boneco

1. Abra o boneco.
2. Aba **Animações** → ícone da pasta (**Usar animações de outro boneco**).
3. Marque **Esqueleto padrão**.
4. Olhe a tabela: **combinam 14 de 14**? Bom.
5. Escolha **Cópia** (para mexer só neste) ou **Ligadas**.
6. Clique **Usar as animações**.

## O andar de um boneco em outro (o jeito do Fortnite)

1. Ponha os bonecos no mesmo projeto: **Base → Trazer uma base de fora…**
2. No boneco que é o **dono** (ex.: cavaleiro), tenha o andar pronto.
3. Clique no outro boneco (ex.: goblin), na lista **Bases**.
4. **Animação → Animações de outro boneco…**
5. Marque **cavaleiro — base deste projeto**.
6. Escolha **Ligadas — mudam junto com o original**.
7. Clique **Usar as animações**.
8. O andar aparece em **Compartilhadas**, com **↗ do cavaleiro**.

## Mudar num lugar, todos mudam

1. No goblin, em **Compartilhadas**, clique **Abrir o original**.
2. O programa vai para o cavaleiro, com o andar aberto.
3. Mude o andar.
4. Volte ao goblin: ele já anda do jeito novo.
5. **Salvar** grava também `cavaleiro-animacoes.bone`, para o jogo.

## Boneco com nomes de osso diferentes

1. Faça igual ao de cima.
2. A tabela **Combinar os ossos** acha `braco_direito → braco_d` sozinha.
3. Onde diz **FALTA**, escolha o osso na lista.
4. **Ligadas**: os ossos daqui ganham os nomes de lá. A janela mostra quais, antes.
5. **Cópia**: nada é renomeado; as chaves vêm com os nomes daqui.

## Dar ao boneco os nomes do Esqueleto padrão, de uma vez

1. **Base → Seguir o Esqueleto padrão…**
2. Confira a tabela.
3. **Renomear os ossos**.
