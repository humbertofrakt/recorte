# documentos/

Tudo que é texto e não é código.

| Pasta ou arquivo | O que é |
|:---|:---|
| `manual/` | O manual de uso, 8 capítulos, em português. `manual/en/` é a versão em inglês |
| `pesquisa/` | O que os outros programas fazem. Relatórios por programa, a pesquisa de menus e a leitura dos manuais |
| `planos/` | Os planos de cada rodada, o projeto do menu e a lista de possibilidades. Cada plano tem a seção "Desvios" no fim |
| `notas-de-desenvolvimento/` | Pedidos entre donos de cada fase, dúvidas da especificação, e o script de conferência no Chrome |
| `MANUAL DE REQUISITOS 2026-09-06.md` | Os 55 requisitos do produto, base de tudo. Documento parado: consulta, não trabalho do dia |

Ordem para quem chega: manual → planos → pesquisa.
